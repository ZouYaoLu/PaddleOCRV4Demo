# PaddleOCR  测试示例

这是一个基于 .NET 8 和 Windows Forms 开发的飞桨 PaddleOCR 模型测试示例，用于验证不同中文 OCR 模型的性能和效果。

## 功能特性

- **多模型测试**: 支持8种不同的中文PaddleOCR模型（V2-V5，轻量版到服务器版）
- **性能对比**: 可切换不同模型进行性能和精度对比测试
- **GPU加速**: 支持CUDA + TensorRT加速，测试GPU性能提升效果
- **智能下载**: 自动检测和下载所需的飞桨模型文件
- **图片识别**: 支持多种图片格式的OCR文字识别测试
- **结果展示**: 详细显示识别结果、置信度和执行时间

## 使用说明

1. **选择模型**: 在下拉菜单中选择要测试的PaddleOCR模型
2. **下载模型**: 点击"立即下载"或"重新下载"按钮获取模型文件
3. **初始化引擎**: 点击"初始化引擎"按钮加载选中的模型
4. **选择图片**: 点击"选择图片"导入测试图片
5. **开始识别**: 点击"开始识别"进行OCR测试
6. **查看结果**: 在右侧查看识别结果和性能数据

## 界面说明

- **模型选择**: 左上角下拉菜单，选择不同的飞桨模型进行测试
- **下载按钮**: 智能显示"立即下载"或"重新下载"状态
- **配置选项**: 文字角度识别、GPU加速等测试选项
- **图片区域**: 左侧显示待识别的测试图片
- **结果区域**: 右侧显示OCR识别结果和执行时间
- **状态栏**: 底部显示当前操作状态和模型信息

## 测试模型

支持以下飞桨PaddleOCR模型的性能测试：

- **中文V5 (推荐)** - 最新移动端优化版本
- **中文V3轻量版** - 速度最快的轻量模型
- **中文V4** - 当前稳定版本
- **中文V3** - 标准版本
- **中文服务器V5** - 精度最高的服务器版本
- **中文服务器V4** - 高精度服务器版本
- **中文服务器V2** - 经典服务器版本
- **中文V2** - 基础版本

## 技术栈

- **.NET 8** - 现代化的跨平台框架
- **PaddleSharp** - 飞桨.NET推理库
- **CUDA + TensorRT** - GPU加速支持
- **Windows Forms** - 简洁的桌面界面

## 运行环境

- Windows 10/11
- .NET 8.0 运行时
- 可选：NVIDIA GPU + CUDA 12.x + TensorRT（用于GPU加速测试）


## 注意事项

- 这是一个测试示例项目，用于验证飞桨模型性能
- 首次使用需要下载模型文件，请保持网络连接
- GPU测试需要安装CUDA和TensorRT环境
- 建议使用清晰的图片进行测试以获得准确的性能数据
